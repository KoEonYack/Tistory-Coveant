# 성경공부 글 작성 규칙

이 디렉터리와 하위 디렉터리의 성경공부용 Markdown 글에는 다음 형식을 적용합니다.

## 섹션 간격

- 도입 문단 뒤와 각 섹션이 끝난 뒤에는 아래 블록으로 충분한 여백을 둡니다.

```html
<br />
<br />
<br />
```

- 각 섹션 제목은 `# 제목` 형식을 사용합니다.
- 제목 바로 아래에는 빈 줄 하나를 둔 뒤 `<br />`를 한 줄 넣고, 다시 빈 줄을 둔 뒤 본문을 시작합니다.
- 표, 인용문, 목록도 해당 섹션의 본문으로 두며, 섹션 끝의 여백 블록 뒤에 다음 제목을 둡니다.

## 본문 작성

- 문단 사이에는 빈 줄 하나를 둡니다.
- 줄바꿈을 표현할 때 Markdown의 끝 공백 두 칸을 사용하지 않고 `<br />`를 사용합니다.
- 이미지 경로와 외부 링크는 실제 문서 위치를 기준으로 확인합니다.
- 제목, 표, 인용문, 목록의 Markdown 문법은 표준 형식을 유지합니다.

## 문체

- 설명 문장은 기본적으로 `합니다`체를 사용합니다. 예: `보여 줍니다`, `읽을 수 있습니다`, `중요합니다`.
- 해설 문장에 `~한다`, `~이다`, `~된다`와 같은 평서형 문체를 섞지 않습니다.
- 성경 본문 인용과 고유명사는 원문 또는 통용 표기를 유지합니다.
