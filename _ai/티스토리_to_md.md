아래 티스토리 게시글을 저장소의 마크다운 파일로 백업해줘.

원본 글: `{티스토리_게시글_URL}`  
저장할 마크다운 파일: `{저장소_절대경로}/게시글.md`  
이미지 저장 폴더: `{저장소_절대경로}/img`

요청 사항:

1. 원본 게시글의 제목, 본문, 문단 순서, 줄바꿈, 링크, 강조 표현, 이미지, 구분선을 빠짐없이 백업해줘.
2. 티스토리 마크다운 모드에 이 파일 내용을 다시 붙여 넣었을 때, 원본 글과 최대한 동일하게 보이도록 작성해줘.
3. 원본에 있는 이미지 전체를 다운로드해 `img` 폴더에 저장해줘. 파일명은 본문 순서가 드러나도록 `01_설명.jpg`처럼 정리해줘.
4. 본문의 이미지는 로컬 상대경로가 아니라 아래 형식의 GitHub raw URL로 작성해줘. 한글 경로와 파일명은 URL 인코딩해줘.

   `https://raw.githubusercontent.com/KoEonYack/Tistory-Coveant/refs/heads/master/{Article_하위_경로}/img/{파일명}`

5. 원본의 구분선이 아래 형식이면 마크다운 파일에서도 정확히 같은 태그를 사용해줘.

   `<hr contenteditable="false" data-ke-type="horizontalRule" data-ke-style="style1">`

6. 원문을 임의로 요약하거나 문체를 다듬지 말고, 오탈자와 띄어쓰기까지 원문을 유지해줘.
7. 완료 후에는 다음을 확인해줘.
   - 본문에 포함된 이미지 수와 다운로드한 이미지 수가 같은지
   - 이미지 파일이 모두 `img` 폴더에 존재하는지
   - 이미지 주소가 모두 GitHub raw URL인지
   - 원본과 동일한 구분선 태그가 사용됐는지

완료되면 저장한 마크다운 파일과 이미지 폴더 경로를 알려줘.
